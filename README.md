## The emoji

> **🌻**

A sunflower is sunshine you can send. It is warm at first glance with no context needed, universal across ages and backgrounds, and chosen rather than the default smiley — while staying friendly without intimacy, sarcasm or flirtation, so it reads exactly right coming from a stranger.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Deterministic, offline, no dependencies: `main.ts` (Node 22) writes the single emoji to `/output/entry.txt` with no trailing newline.
